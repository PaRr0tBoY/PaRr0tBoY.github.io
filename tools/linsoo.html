AI Provider
Custom 命名
Base URL
OpenAI 兼容 chat completions 端点；留空沿用默认智谱 AI 地址。
API Key get key
优先保存在浏览器 OPFS 或 IndexedDB；若两者都不可用，则继续回退到 localStorage。新页面会尝试读取原 Linso 的 API 配置作为初始值。
Model 可手动输入
按 Enter 或点击候选模型加入调用列表；第一个模型优先调用。获取到的模型只作为候选，不会自动进入调用列表。
System Prompt
这个提示词用于“搜索回答”模式，不再要求模型输出查询词 JSON。
Search Providers
纯静态页面会从浏览器直接请求搜索 API；API Key 会优先保存在浏览器 OPFS/IndexedDB，必要时回退到 localStorage。部分服务可能因 CORS 拒绝前端请求。
单次搜索返回条数
分别对应 3 / 6 / 9 条结果。
搜索国家
只允许从中国、新加坡、马来西亚、美国、日本、韩国中选择；Exa 使用地区代码，Serper / SerpAPI 使用国家代码，Tavily 会尽量同步映射。
高德地图 Key
当问题涉及当前位置、附近、出行路线或基于你所在位置的天气时，会先请求浏览器定位权限，再调用高德 Web 服务 API。
Jina Reader API Key
用于通过 Jina Reader 抓取提权网页或工具指定网页的完整正文；未填写时按 Jina 匿名额度尝试，失败后不会再走本地匿名抓取。
来源提权
提权域名会在未来搜索结果中优先排序，并把命中网页的完整正文作为高权重上下文发送给 AI。
来源屏蔽
屏蔽域名会从未来 Web Search 结果中直接剔除，也不会出现在来源面板、搜索页或发送给 AI 的搜索上下文里。
Theme
对话索引

数据持久化
默认优先使用 OPFS；若 OPFS 或 IndexedDB 不可用，则会继续自动回退。
配置
导出或导入 AI Provider、模型列表、System Prompt、搜索 Provider、高德地图 Key、Jina Reader Key 与来源偏好；不会覆盖通用与外观设置。
消息记录
消息记录会优先保存在浏览器 OPFS/IndexedDB 中；若两者都不可用，则回退到 localStorage。导入会合并到当前本地记录。
