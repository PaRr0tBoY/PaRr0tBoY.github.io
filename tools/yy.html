完形填空 Cloze Test

完形考20个空，每空0.5分，共10分。它不只考单词和语法，更考 「空格上下文逻辑」——即空与上下文之间的逻辑关系与一致性。 近年命题人逐渐弱化词汇语法考察，逻辑性与一致性成为核心考点。

核心心法

空格上下文逻辑

完形的考察本质可概括为七个字：空格上下文逻辑。每个空既受上文制约，也受下文牵引，做题时不只往下读，更要前后联动，找到主旨句和逻辑线索。

上文出现"阴阳"，下文出现"万事万物"→ 空格处应填表示对立统一关系的词。
逻辑性考点

逻辑关系词优先

优先攻克包含逻辑关系词的题目：顺承（and, moreover, therefore）、转折（however, otherwise）、因果（because, since）。遇到但、然而、却等转折词，上下文意思通常相反。

一致性考点

指示代词与衔接

指示代词（this/that/these/those）、人称代词、不定代词、定冠词、比较级等功能词，是考察一致性的关键。选项与空前后出现同一指示代词时，大概率心心相应。

考场步骤

先读第一句，再定逻辑题

完形第一句几乎不受控，是主旨句。建议先读懂第一句，再优先把包含逻辑关系词和指示代词的题目做对，这些是"凭技巧就能拿下"的分数。

第一句是总分结构→ 全文主旨已在开头交代，通读全文反而浪费时间。
蒙题大法

动词选项最先原则

四个选项均为动词时，选"最先发生"的那个动词。如produce（产生）→ apply（应用）→ maintain（维持），产生最先发生，选produce。

选项：prove / persist / remember → 有了发现才能证明、坚持、记住，选prove。
概率兜底

ABCD平均分布法

完形答案ABCD近似平均分布（各5个左右）。实在不会时，先统计已确定题目的选项分布，把缺失的选项补到剩余空中，兜底保2.5分甚至更高。

已确定A5 B4 C4 D3→ 剩余空优先补D，使各选项趋于均衡。

英语翻译 Translation

翻译考一篇长难句，评分标准为「准确、通顺、完整」。核心要求是 信达雅：在保证准确的基础上，尽量译得文雅，常用四字俗语提升档次。 原文事实句只能译为事实句，不能随意替换成观点句。

✓ 做

  • 中语原文：不能删减，也不能增添原文的实词信息
  • 信达雅：准确的基础上追求文雅，如"身无分文"而非"I have no money"直译
  • see + 抽象内容译为"发现/觉察/得知"，see + 具体内容译为"看"
  • 从直译逐步调整，写出人化、满足大纲要求的译文

✕ 不做

  • 不要把事实句替换成观点句（如"我吃了很多"≠"我很饿"）
  • 不要为了追求雅致而擅自添加原文没有的词（如"夜难以昧"添加了"夜"）
  • 不要忽略评分标准中的"完整"，信息缺失直接扣分
  • 不要只重词汇语法而忽视上下文的准确理解

新题型 New Question Types

英语一新题型包含三种：七选五、排序题、小标题，每年从中随机抽考一种，20分。 新题型最大的特点是选项相互不独立——错一题会连锁影响后续题目，所以必须整体把控文章逻辑。

01

先学方法论

先听方法论，再拿真题练习。不要直接刷05-09年旧题，音质和方法已过时。

02

梳理文章逻辑

新题型不依赖文章字面意思，依赖语段连贯性与一致性。梳理逻辑后，不依赖原文意思也能做题。

03

控制做题时间

建议二十分钟完成新题型，与阅读理解时间一致。新题型文章更长（550-600词），压力更大。

七选五

句段连贯与一致性

七个选项选五个，核心考查段落之间的逻辑衔接。遇到but（转折）、because（因果），上下文关系立刻清晰。

出现but→ 上下文意思相反；出现because→ 上下文存在因果关系。
排序题

段落顺序重建

英语一独有题型。通过代词、冠词、前后句子的衔接关系，将打乱的段落还原成连贯文章。

代词"this"指代前文→ 该段应紧接包含指代对象的段落之后。
小标题

主旨句匹配

英语一和英语二都考。每段小标题必须概括全段主旨，练真题时可跨英一英二互练。

做完英一小标题→ 拿英二小标题继续练，真题最宝贵。
关键特点

选项相互不独立

与阅读理解不同，新题型选项互相关联。41题选错了，44题可能因选项已被占用而必错——一错连错。

41题选C后，44题原本应选C也不可选→ 连锁失分。

考场策略 Exam Strategy

01

时间分配

阅读40分钟、新题型20分钟、翻译25分钟、作文35分钟。三小门合计约30分钟，不要超时。

02

复习优先级

完形：逻辑关系词 + 指示代词优先；翻译：评分标准 + 信达雅；新题型：先方法论后真题。

03

心态建设

三小门分数虽小，却是拉开差距的关键。大家都重视阅读写作时，你在三小门稳拿分，就是优势。
