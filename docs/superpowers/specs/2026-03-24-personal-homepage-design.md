# 个人主页设计规格

## 概述

- **文件**: `/index.html`（GitHub Pages 根目录）
- **定位**: GitHub Pages 个人主页，单文件静态页面
- **功能**: 展示个人形象 + 跳转所有工具
- **风格**: Jony Ive 设计语言，深色模式默认，留白充足，字体层级分明

---

## 页面结构

```
┌─────────────────────────────────────┐
│            Hero 区域                 │
│   昵称 "Ryan" + 一句话介绍           │
│   [头像]                            │
└─────────────────────────────────────┘
┌─────────────────────────────────────┐
│            关于我                   │
│   背景、兴趣、方向（3-4段文字）       │
└─────────────────────────────────────┘
┌─────────────────────────────────────┐
│            工具集                   │
│   ┌────┐ ┌────┐ ┌────┐ ┌────┐     │
│   │Linso│ │MathB│ │FlowD│ │ ... │   │
│   └────┘ └────┘ └────┘ └────┘     │
│   2列/3列自适应网格卡片              │
└─────────────────────────────────────┘
┌─────────────────────────────────────┐
│            底部                     │
│   GitHub  ·  邮箱  ·  RSS           │
└─────────────────────────────────────┘
```

---

## 组件规格

### Hero 区域

- 大标题：昵称（Ryan），字号 3rem，字体加粗
- 副标题：一句话介绍，1.2rem，颜色偏淡
- 头像：圆形，80px，CSS 占位（实际头像用户自行替换）
- 垂直居中，上下留白充足

### 关于我

- 标题："关于我"，左侧细线装饰
- 正文：3-4段个人描述，内容从项目背景提取
- 左侧小标签标识技能方向（如：机械 + 软件 / AI 应用 / 效率工具）

### 工具集

- 标题："工具集"
- 工具卡片：2-3列自适应网格（CSS Grid + `@media`）
- 每个卡片：工具名称 + 一句话描述 + 跳转链接
- 悬浮态：轻微上浮 + 边框高亮
- 工具列表自动扫描 `tools/` 目录所有 `.html` 文件
- 工具名称：读取 `<title>` 标签，无则用文件名

### 底部

- 社交链接：GitHub、邮箱
- 居中，字号偏小，颜色偏淡

---

## 技术细节

- **单文件**: HTML + 内联 CSS + 内联 JS
- **无构建步骤**: 纯静态，复制即用
- **CDN**: 无外部依赖（字体用系统字体栈）
- **深色模式**: 默认深色，页面顶部提供浅色切换按钮
- **状态持久化**: 主题偏好存 `localStorage`
- **工具扫描**: JS 静态扫描 `../tools/` 路径下的 HTML 文件
- **响应式**: 移动端单列，桌面端多列

---

## 行为约束

- 工具集加载时：若扫描失败，显示手动配置提示
- 头像：使用 CSS 生成的占位图形，用户自行替换图片路径
- 页面内无 AI 功能，纯展示型
