Overview

Volante is a curated community mod pack for Vivaldi Browser. It bundles 20+ CSS mods and JS scripts to transform the Vivaldi experience. One command, endless customization.

Mods Included

  • VivalArc Arc-style layout transformation with floating tab bar
  • VividPeek Arc-style link preview when hovering over links
  • TidyTabs Restore pinned tabs and smart tab management
  • VividPlayer Sidebar media controller
  • VividToast Modern notification system
  • Quietify Noise reduction and cleaner UI

Installation

Run the following command in your terminal:

curl -fsSL https://raw.githubusercontent.com/PaRr0tBoY/Awesome-Vivaldi/main/install.sh | bash

Or download the mod files manually and copy them to your Vivaldi mods directory.
