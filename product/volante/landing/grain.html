The Collection

One cohesive vision.

Each mod is independent. Mix, match, or install everything at once. Every piece respects Vivaldi's native architecture.

CSS

VivalArc

The foundation. Redesigns the entire UI from scratch — new tab strip, sidebar, toolbar. Three layout options: left sidebar, top compact, bottom nav. Every other mod builds on this.

JS + CSS

VividPeek

Hold Ctrl/Cmd and hover any link to preview it in a floating panel. Browser-native, zero latency. Stay in flow without opening new tabs.

JS + CSS

TidyTabs

AI-powered tab grouping and cleanup. Automatically organizes your tabs into meaningful workspaces using LLM classification. Manual stacks get smart renaming.

JS + CSS

VividPlayer

A sidebar media controller with Picture-in-Picture. Album art, progress scrubbing, playback controls — all in one place. Works with any media playing in Vivaldi.

JS + CSS

VividToast

Toast notifications for mod events. Download complete, tab grouped, theme switched — always informed, never interrupted. Customizable duration and style.

CSS

Quietify

Hides audio indicators, mutes tab clutter, strips away visual noise. Keeps only what matters. The sound of silence, Vivaldi edition.

Get Started

One command. That's it.

The interactive TUI installer auto-discovers your Vivaldi installation, lets you pick exactly which mods you want, and handles everything. Fully reversible at any time.

1

Install

Paste the one-liner into your terminal. The interactive TUI launches automatically.

Windows
irm https://raw.githubusercontent.com/PaRr0tBoY/Awesome-Vivaldi/main/install.ps1 | iex
macOS / Linux
curl -fsSL https://raw.githubusercontent.com/PaRr0tBoY/Awesome-Vivaldi/main/install.sh | bash
2

Customize

Browse the catalog, toggle what you want. The interactive picker handles dependencies and explains each mod. Reversible at any time — run the command again to add or remove mods.

3

Restart

Restart Vivaldi. Your reimagined browser is ready.
